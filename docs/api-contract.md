# SidePeace API Contract

Agreed between the extension (client) and the FastAPI backend (server). Both test suites read the example files in `docs/contract/` so a field-name mismatch fails a test.

- **Base URL:** `http://localhost:8000`
- **Format:** JSON request and response bodies, `Content-Type: application/json`
- **Requirements:** REQ-F02 (validated input, no secrets), REQ-Q02 (every failure returns a safe fallback), REQ-F03 (persisted session history)

## Shared rules

| Field | Rule | Notes |
|---|---|---|
| `session_id` | string, 1–64 chars, `^[A-Za-z0-9_-]+$` | Generated by the extension, stored in `chrome.storage` |
| `turn.index` | integer, ≥ 0 | Position of the turn in the chat, starting at 0 |
| `turn.role` | `"user"` or `"model"` | |
| `turn.text` | string, 1–20000 chars | A finished turn (debounced, final text only) |
| `text` (query) | string, 1–2000 chars | Limit is ONE constant shared by backend and side panel |

## GET /health
Liveness check. **200** `{"status": "ok"}` (`docs/contract/health-response.json`)

## POST /sync
Saves one finished chat turn into the session's history.

- **Request:** `docs/contract/sync-request.json`
- **200:** `docs/contract/sync-response.json` — `turn_count` is how many turns the session now holds.
- **Idempotent:** sending the same `session_id` + `index` again replaces that turn's text; `turn_count` does not grow.

## POST /query
Asks a side question. The backend builds an isolated prompt from the session's pruned history plus the question, asks the LLM, and returns the answer. The user's main Gemini chat is never touched.

- **Request:** `docs/contract/query-request.json`
- **200:** `docs/contract/query-response.json`
- A session with no synced turns is allowed (empty context).

## Errors
Every non-2xx response has exactly this shape (`docs/contract/error-*.json`):

```json
{ "error": "<machine_code>", "message": "<safe text for the user>" }
```

| HTTP | `error` | When |
|---|---|---|
| 422 | `validation_error` | Missing field, wrong type, empty or too-long text, bad `session_id`, bad `role` |
| 429 | `provider_rate_limit` | The LLM provider rate-limited us |
| 502 | `provider_bad_response` | The provider returned an empty or unusable response |
| 504 | `provider_timeout` | The provider took too long |
| 500 | `storage_error` | Database failure |
| 500 | `internal_error` | Anything unexpected (logged on the server) |

Rules:
- `message` never contains a stack trace, file path, SQL or API key.
- FastAPI's default 422 body is `{"detail": [...]}`. The Gateway **must** register a handler that converts it to the shape above.
- The extension turns these into its own typed errors: network failure → `NetworkError`, 422 → `ValidationError`, 429/500/502/504 → `ServerError`.

## Out of scope for M2
Authentication, multiple users and streaming responses.
